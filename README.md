# 🛍️ Customer Shopping Behavior Analysis

**An End-to-End Data Analytics Project | Python • SQL • PostgreSQL • Power BI**

## 📌 Project Overview

Customer behavior analysis plays an important role in understanding purchasing patterns, improving customer retention, and making data-driven business decisions.

This project analyzes customer shopping behavior using a dataset containing **3,900 customer records and 18 original attributes**. The objective is to identify purchasing trends, evaluate customer preferences, analyze revenue performance, and understand how factors such as discounts, subscriptions, shipping methods, and demographics influence shopping behavior.

The project follows an end-to-end data analytics workflow, starting with data exploration and cleaning in Python, followed by SQL-based business analysis and interactive dashboard development in Power BI.

## 🎯 Business Objectives

- Analyze customer purchasing patterns and preferences.
- Compare revenue generated by male and female customers.
- Understand the impact of subscription status on customer spending.
- Identify products with the highest average customer ratings.
- Evaluate discount usage and shipping preferences.
- Segment customers based on their purchasing history.
- Identify top-selling products across different categories.
- Analyze revenue contribution across different age groups.

## 📂 Project Workflow

### 1. Data Exploration & Cleaning – Python

Used Python and Pandas to explore and prepare the raw customer shopping dataset.

Key activities:
- Inspected dataset structure, dimensions, data types, and statistical summaries.
- Identified missing values in the Review Rating column.
- Handled missing ratings using category-wise mean imputation.
- Standardized column names into lowercase snake_case format.
- Created an `age_group` column using `pd.qcut()` to segment customers into four age groups.
- Converted purchase frequency into numerical days using a mapping dictionary.
- Identified identical information in the Discount Applied and Promo Code Used columns and removed the redundant column.

### 2. Database Integration – PostgreSQL

Loaded the cleaned dataset into PostgreSQL using SQLAlchemy and psycopg2.

- Established a Python-to-PostgreSQL connection.
- Transferred the cleaned Pandas DataFrame into a PostgreSQL table.
- Prepared structured data for SQL-based business analysis.

### 3. Business Analysis – SQL

Developed SQL queries to answer 10 business questions using aggregation, filtering, subqueries, conditional logic, CTEs, and window functions.

| No. | Business Question | SQL Concepts |
|---|---|---|
| 1 | What is the total revenue generated by male vs. female customers? | GROUP BY, SUM |
| 2 | Which customers used discounts but spent above the average purchase amount? | Subquery, WHERE |
| 3 | What are the top 5 products with the highest average review ratings? | AVG, ORDER BY, LIMIT |
| 4 | How do average purchase amounts compare between Standard and Express shipping? | WHERE, AVG |
| 5 | Do subscribed customers spend more than non-subscribers? | GROUP BY, COUNT, AVG, SUM |
| 6 | Which 5 products have the highest discount usage percentage? | CASE WHEN, Aggregation |
| 7 | How can customers be segmented into New, Returning, and Loyal customers? | CASE WHEN, GROUP BY |
| 8 | What are the top 3 most purchased products within each category? | CTE, ROW_NUMBER(), PARTITION BY |
| 9 | Are repeat buyers also likely to subscribe? | Filtering, GROUP BY |
| 10 | What is the revenue contribution of each age group? | GROUP BY, SUM, ORDER BY |

### 4. Interactive Dashboard – Power BI

Developed an interactive Power BI dashboard to present important customer behavior metrics and business insights.

**Key Performance Indicators (KPIs):**
- Total Number of Customers
- Average Purchase Amount
- Average Review Rating

**Dashboard Visualizations:**
- Customer distribution by subscription status.
- Revenue by product category.
- Sales by product category.
- Revenue by age group.
- Sales by age group.

**Interactive Filters:**
- Subscription Status
- Gender
- Product Category
- Shipping Type

The dashboard allows users to explore customer segments and compare purchasing behavior across different dimensions.

## 📊 Key Business Insights

## 🚀 How to Run the Project

**Step 1: Clone the repository**

```bash
git clone <your-github-repository-url>
```

**Step 2: Install required Python libraries**

```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary
```

**Step 3: Run the Jupyter Notebook**

Open `Customer_behavior_analysis.ipynb` in Jupyter Notebook and execute the cells.

**Step 4: Configure PostgreSQL**

- Create a PostgreSQL database.
- Update the database connection settings.
- Execute the notebook cells to load the cleaned dataset into PostgreSQL.

**Step 5: Execute SQL queries**

Open `customer_shopping_behavior_sql_queries.sql` in your SQL editor and execute the business analysis queries.

**Step 6: Explore the Power BI Dashboard**

Open `customer_shopping_behavior_dashboard.pbix` using Power BI Desktop and interact with the dashboard filters and visualizations.
